# Tutorials

Four lessons, in order, from install to a finished optimization. Each one is
a single path with visible results at every step and runs on a plain
`pip install vmex` CPU install; the code is literal-included from scripts in
the repository's `examples/` directory, which CI executes.

```{toctree}
first-optimization
```
